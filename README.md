# CMD YouTube Player

A lightweight terminal-based YouTube player using VLC and yt-dlp for Windows. Runs on slow machines.
Search videos, queue playback, and enjoy autoplay recommendations directly from your command line.

---

## Features

- YouTube video search
- VLC playback integration
- Queue system (add / play next)
- Autoplay engine
- Recommended videos based on current playback
- Simple terminal interface (no GUI)

## Requirements

Before running this project, install:

- Python 3.10+
- VLC Media Player
- yt-dlp (`pip install yt-dlp`)

Make sure VLC is available in your system PATH.

---

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/cmd-youtube-player.git
cd cmd-youtube-player
```

## Platform

- OS: Windows
- Architecture: x64
- Language: Python

## Requirements

- VLC Media Player installed
- Windows 10/11 recommended
